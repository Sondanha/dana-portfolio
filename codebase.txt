# Son Danha Portfolio - Codebase Reference

## Project Overview
구직 및 비즈니스 파트너십 어필을 위한 모듈형 포트폴리오 웹사이트.
DH 모노그램의 네이비·코럴·골드 팔레트를 확장한 라이트 모드 정적 사이트.

## Tech Stack
- **Framework**: Astro 5.x (Static SSG)
- **Styling**: Tailwind CSS v4 (@tailwindcss/vite plugin)
- **Animation**: Framer Motion (React Islands, LazyMotion)
- **Interactive UI**: React 19 (@astrojs/react, Astro Islands)
- **SEO**: @astrojs/sitemap, Schema.org JSON-LD
- **Deploy**: Cloudflare Pages (Static, no adapter needed)
- **Fonts**: Inter (EN) + Pretendard Variable (KR)

## Architecture Decisions
1. **Astro Islands Pattern**: React components are only hydrated where interactivity is needed (animations, hover effects). Static content ships 0KB JS.
2. **LazyMotion**: All Framer Motion components use `LazyMotion` + `domAnimation` to minimize bundle size (~27KB gzip vs ~40KB full).
3. **Single Data Source**: All content lives in `src/data/portfolio.json`. Sections read from this file at build time.
4. **Modular Sections**: Each section is an independent component. Reorder by changing import order in `src/pages/index.astro`.
5. **CSS Variables for Design Tokens**: All colors, fonts, spacing defined as CSS custom properties in `src/styles/global.css` via Tailwind v4 `@theme`.

## Folder Structure
```
src/
├── components/
│   ├── layout/          # Header, Footer (Astro, static)
│   ├── sections/        # Hero, Now, Projects, Skills, Timeline (Astro, static shell)
│   └── ui/              # AnimatedBentoCard, ProjectCard, AnimatedTimeline (React, interactive)
├── data/
│   └── portfolio.json   # All content data
├── layouts/
│   └── BaseLayout.astro # HTML shell, SEO meta, fonts, global styles
├── pages/
│   └── index.astro      # Single-page assembly
└── styles/
    └── global.css       # Tailwind v4 @import + @theme design tokens
```

## Naming Conventions
- **Astro components**: PascalCase.astro
- **React components**: PascalCase.tsx
- **Directories**: kebab-case
- **CSS variables**: --color-*, --font-*, --spacing-*, --radius-*
- **Data IDs**: kebab-case (e.g., "mobile-ai-product", "ai-data")

## Design System
- **Palette**: Warm light mode. Midnight navy (#17243e), coral (#e85d3f; accessible text tone #c54b32), and gold (#f2b84b) brand accents with ivory surfaces.
- **Typography**: Bold, large headings (text-5xl to text-8xl). Clean body text (text-sm to text-lg).
- **Layout**: Max-width 6xl (1152px). Generous section padding (7rem). Bento Grid with 1rem gap.
- **Cards**: Rounded-xl, subtle border/shadow, restrained hover elevation.
- **Animations**: Viewport-triggered (once). Fade-in + slide-up for cards. Stagger for lists.

## Client Directives (Astro Islands)
- `client:visible`: Used for all animated components (loads JS only when scrolled into view).
- `client:visible={{ rootMargin: '200px' }}`: Pre-loads 200px before entering viewport for smoother experience.
- No `client:load` used (no above-the-fold interactive components).

## Data Schema (portfolio.json)
- `meta`: Site metadata (name, title, description, social links)
- `hero`: Main headline, subheadline, CTA
- `now`: Current role and status
- `projects[]`: id, title, category, description, tags, thumbnail, thumbnailPosition, links, featured, gridSpan
- `skills[]`: id, category, icon, description, items
- `timeline[]`: id, period, title, description, type (achievement|education|activity), link
